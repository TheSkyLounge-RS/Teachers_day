# Teachers_Day.exe — Pranam Sir

A static cinematic Teachers' Day website made with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. For the smoothest experience, use VS Code Live Server or any local static server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. In GitHub: **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`, then Save.
5. Open the generated Pages URL.

No Firebase or backend is required.
